## Сборка и запуск

Нужны GCC с поддержкой C++17 и Python 3. Для Windows подходит MSYS2 UCRT64 с каталогом `C:\msys64\ucrt64\bin` в PATH. Выполняйте команды в папке `lab6`.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
.\lab6.exe data/G1.txt both
.\lab6.exe data/G2.txt exact
.\lab6.exe data/G3.txt ant 20 12000 1 3 0.2 32 12
~~~

Скрипт собирает `lab6.exe` в корне лабораторной, запускает функциональные тесты и сверяет сохранённые результаты экспериментов с исходными CSV.

~~~text
lab6 GRAPH exact|ant|both [REPEATS [SEED [ALPHA BETA RHO ITERATIONS ANTS]]]
~~~

По умолчанию выполняется один запуск с начальным состоянием генератора 1. Параметры муравьиного метода по умолчанию — `1 3 0.2 32 12`. Повторы используют последовательные начальные состояния. В режимах `exact` и `both` поддерживается до 11 портов, в режиме `ant` — до 200.

Результат выводится в CSV. Поля `hours` и `cost` содержат метрики маршрута, `time_ns` — длительность поиска. Статус `infeasible` означает, что перебор доказал отсутствие допустимого пути. Статус `not_found` означает, что муравьиный алгоритм исчерпал отведённые попытки.

## Входные данные

Первая строка содержит число портов и общий бюджет. Вторая строка содержит уникальные имена портов без пробелов из латинских букв, цифр, `_` и `-`. Далее идут пары `время стоимость` в порядке строк верхнего треугольника матрицы, для всех `i < j`. Каждая пара описывает переход в обоих направлениях. Метки существующего перехода — целые числа от 1 до 10⁹. Пара `0 0` обозначает отсутствующий переход. Бюджет — целое число от 0 до 200·10⁹.

Пример графа из трёх портов с бюджетом 4.

~~~text
3 4
A B C
1 8  6 2
2 2
~~~

Решение — `A -> C -> B` или обратный путь. Длительность составляет 8 часов, стоимость — 4 условные денежные единицы.

## Исследование и отчёт

~~~powershell
python scripts/graphs.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Benchmark
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Report
~~~

Команда `-Benchmark` повторяет параметризацию и замеры, заменяет CSV и автоматически обновляет таблицы для отчёта. Числа в готовом PDF относятся к сохранённой серии. Для обновления PDF используйте `-Report`. Сборка отчёта требует XeLaTeX, Times New Roman, Arial и Consolas.

## Состав

- `src/` — реализации на C++17 и командный интерфейс.
- `tests/verify.py` — независимый эталон для 20 графов, проверки бюджета, допустимости и ошибок ввода.
- `tests/verify_results.py` — проверка маршрутов, статистики параметризации и медиан времени по CSV.
- `scripts/` — генерация графов, запуски алгоритмов и подготовка результатов для XeLaTeX.
- `data/` — три полных графа для параметризации и семь графов для замеров. Метки синтетические.
- `results/` — эталонные маршруты, 1620 запусков параметризации, 98 замеров, сводные таблицы и результаты проверок.
- `report.tex`, `docs/`, `shared/` и `figures/` — исходники отчёта и редактируемые векторные рисунки TikZ. Преамбула взята из ЛР4 этого репозитория.
- `output/pdf/` — итоговый отчёт.
