# ЛР4: задание и принятые решения

Источник: сообщение пользователя от 12.11.2026. Требуется любой метод сегментации чёрно-белых изображений, последовательная и параллельная реализации, схемы каждого вида потока, функциональные тесты и реальные замеры. Предпочтителен C. Число рабочих: 1, 2, 4, 8, ... до 8k, где k — число логических ядер. Самостоятельную последовательную версию необходимо сравнить с параллельной при q=1.

Выбран метод Оцу, бинарная сегментация восьмибитного полутонового изображения. Рентгеновские снимки в исходном задании приведены как возможный пример, а не обязательный набор. Для воспроизводимости используются учебные синтетические фантомы, без клинических утверждений. Изображения читаются из PGM P5, maxval=255. Для PNG/JPEG можно предварительно экспортировать изображение в этот формат.

## Замечания на фотографиях

1. Один тип операций закреплён за обслуживающим устройством; оно берёт заявку из входной очереди, выполняет свою стадию и передаёт заявку в следующую очередь. Разные устройства моделируются разными рабочими потоками; обсуждаются варианты ожидания сигнала или завершающей заявки.
2. Пример генератора, трёх очередей и трёх обслуживающих устройств с пулом обработанных заявок. На доске явно отмечена ЛР5, диспетчер и формирование статистики после завершения всех заявок.
3. У каждого обслуживающего устройства собственная очередь и фиксированный порядок операций. Общая очередь готовых заявок при нескольких писателях требует синхронизации.
4. При измерении конвейера учитывать обработку и помещение/извлечение заявок. Доступ к очередям синхронизируется; затраты на очереди могут варьироваться.
5. Временная диаграмма конвейера: ожидание при пустой очереди и возможное изменение числа рабочих для несбалансированной стадии.
6. Вопрос о параллельном выполнении при зависимости этапов: следующий этап начинается только после завершения всех необходимых вычислений предыдущего; пример с алгоритмом Винограда.

Первые пять фото относятся прежде всего к конвейеру ЛР5, который в текущем задании ЛР4 не требуется. В ЛР4 реализован параллелизм по данным с локальными гистограммами и барьерной зависимостью фаз. Время управления потоками и ожиданий включено в замер. Порог не вычисляется до готовности всех гистограмм, бинаризация не начинается до публикации порога.
