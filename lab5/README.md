# ЛР5. Конвейер сегментации изображений

[Отчёт в PDF](output/pdf/report.pdf) и его [исходник](report.tex).

Генератор создаёт заявку для каждого имени из командной строки. ОУ 1 считывает изображение, ОУ 2 формирует бинарную маску методом Оцу, ОУ 3 сохраняет маску в отдельный файл. В режиме `pipe` каждое ОУ выполняется в отдельном рабочем потоке. Между генератором и ОУ используются очереди FIFO по два места. В режиме `seq` все операции выполняются последовательно.

## Сборка и запуск

Для Windows нужен GCC MSYS2 UCRT64 с winpthreads. Добавьте `C:\msys64\ucrt64\bin` в `PATH`. Python 3 нужен для создания примера, тестов и замеров. Команды выполняются из каталога `lab5`.

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
python -c "from pathlib import Path; Path('build/input.pgm').write_bytes(b'P5\n4 1\n255\n'+bytes([10,10,200,200]))"
.\lab5.exe seq  build/seq_out  build/input.pgm build/input.pgm
.\lab5.exe pipe build/pipe_out build/input.pgm build/input.pgm
~~~

Программа создаёт выходной каталог. Его родительский каталог должен существовать. Для повторного запуска укажите новое имя выходного каталога. Маски записываются в `000001.pgm`, `000002.pgm` и далее по номеру заявки. В примере порог равен 10, обе маски содержат пиксели `0, 0, 255, 255`. Файл `trace.csv` содержит статусы, пороги и интервалы этапов в миллисекундах от начала замера. Строка в консоли показывает полное время обработки пакета.

Входной файл содержит одно двоичное изображение PGM P5 с максимальной яркостью 255. После 255 нужен один пробельный байт, предпочтительно LF. Комментарии поддерживаются перед числовыми полями. Необрабатываемая заявка получает код ошибки в журнале, последующие заявки продолжают обрабатываться. Итоговый код выхода 1 означает ошибку выполнения, 2 означает неверный вызов.

## Тесты, замеры и пересборка отчёта

~~~powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Benchmark
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Report
~~~

Для замеров нужен matplotlib. Для отчёта нужны XeLaTeX, Times New Roman и Arial. Скрипт замеров обновляет CSV, таблицы и графики. После повторных замеров текст в `results/interpretation.tex` нужно сверить с новыми числами.

- `src/` содержит исходники C11.
- `tests/verify.py` сравнивает маски и пороги с независимым эталоном, проверяет журнал и ошибочные заявки.
- `results/raw.csv` содержит 240 измерений, `summary.csv` содержит медианы и квартили, `timeline_*.csv` содержит журналы для временной диаграммы.
