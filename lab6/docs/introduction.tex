\structuralpart{ВВЕДЕНИЕ}

Цель работы --- сравнить полный перебор и муравьиный алгоритм с элитными муравьями на задаче выбора морского маршрута с ограниченным бюджетом.

По индивидуальному варианту карта портов представлена неориентированным графом. Требуется построить незамкнутый маршрут, посетить каждый порт по одному разу и минимизировать суммарное время переходов при заданном лимите затрат.

Для достижения цели необходимо решить следующие задачи.
\begin{enumerate}
\item Формализовать задачу и описать два метода её решения.
\item Разработать схемы алгоритмов, обосновать корректность и оценить трудоёмкость.
\item Реализовать алгоритмы и проверить их на тестовых данных.
\item Параметризовать муравьиный алгоритм по трём параметрам на одном классе графов. Основным критерием принять максимальное отклонение времени маршрута от эталона.
\item Сравнить методы по времени работы и качеству найденных маршрутов, дать рекомендации по настройке муравьиного алгоритма.
\end{enumerate}
