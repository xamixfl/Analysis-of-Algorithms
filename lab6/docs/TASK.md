# ЛР6. Задание и модель

Индивидуальный вариант, задача lab-aa-06 № 2028. Карта морских переходов между портами представлена неориентированным графом. Требуется минимизировать суммарное время незамкнутого маршрута в пределах общего бюджета. Муравьиный алгоритм использует элитное усиление.

Каждый порт посещается ровно один раз. Начальная и конечная вершины свободны, поскольку в варианте они не заданы. У ребра две симметричные метки — время и стоимость. При равном времени выбирается меньшая стоимость. Для полного перебора результатом может быть доказанное отсутствие допустимого маршрута. Для эвристики исчерпание попыток означает, что за этот запуск маршрут не найден.

По общему заданию нужно описать достоинства и недостатки обоих методов, построить схемы, реализовать алгоритмы и оценить трудоёмкость по схемам. Для существующего ребра в непосещённый порт вероятность выбора должна оставаться положительной. В реализации это обеспечено равномерной составляющей вероятности и нижней границей феромона. Выбор ребра, превышающего остаток бюджета, завершает попытку.

Параметризация проводится по трём параметрам на одном классе из как минимум трёх полных графов, по восемь или больше вершин, с одинаковым разбросом меток. Для каждого графа и сочетания параметров требуется как минимум десять запусков. Критерий качества — максимальное отклонение от эталона. Медиана используется дополнительно. В работе взяты три графа по восемь портов, 20 запусков на граф и сочетание и точный эталон полного перебора. Метки синтетические. Результаты исследования используются для выбора параметров и сравнения методов.
